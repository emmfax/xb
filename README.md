# 小白 · AstrBot 插件 `astrbot_plugin_xbbot` v0.42

> 1:1 复刻 `open.xb.app 9.7.2`，9 系统 + WebUI 9Tab 现代极简管理台，SQLite WAL 全英文存储，`测试testxb/testxb1-8/超管列表` 隔离闭环。

**安装**：AstrBot → 插件 → 上传 `astrbot_plugin_xbbot_v0.42.zip` → 重载即可。

**WebUI 控制台特性（v0.42 升级）**：
- **现代极简通透灰阶设计**：Linear/Vercel 级清爽调色，彻底告别生硬方框与刺眼高饱和度。
- **微型 iOS 胶囊 Switch 开关**：配置中心与指令弹窗统一微型嵌入式设计，无多余占宽与白边。
- **智能折叠与操作保持**：坐骑商城与精灵商城默认折叠收起；增删改时智能保持展开，交互更顺手。
- **全维度表头排序与纯内存秒开**：用户、奴隶、精灵用户支持点击表头即时升降序，搜索防抖毫秒级重绘。
- **小窗口自适应与平滑居中**：Tab 栏带自适应滑动箭头，选中即平滑居中，窄屏下根目录等功能一目了然。
- **统一交互规范**：全页面导出按钮统一为「📥 导出」，导入按钮统一为「📤 导入」，危险操作独立右侧标红隔离。
- **官方 bridge.download 直连**：全量与单文件导出接入 AstrBot 官方下载桥接，彻底突破 iframe 沙箱限制。

**系统与玩法**：
- 涵盖 奴隶/签到/银行/娱乐/精灵/坐骑/帮派/冒险/超管 9 大系统；
- `@QQ` / `@昵称` 均支持深度四级穿透解析；
- 冒险系统 9 大地图 300+ 字沉浸式文案与分支选择；
- 大师球 100% 必中、24 点数学有解递归验证、娱乐互斥锁、转账与红包口令全优化。
