- 📦 **自动清理过期备份（默认保留最新 30 条）**：新增保留备份数量配置与自动清理引擎，杜绝老旧备份堆积；
- ☁️ **Web 控制台直显 WebDAV 连通性测试与一键云端上传**：管理大屏一键测试坚果云/Alist/NAS，即时 Toast 诊断；
- 🛡️ **彻底根除并发事务冲突与回滚异常**：切除跨线程无锁回滚隐患，全底层操作实施安全优雅降级，杜绝聊天群异常报错与死锁假死；
- ☁️ **原生集成 WebDAV 自动云备份**：零依赖纯标准库，支持坚果云/Alist/NAS，定时备份自动静默上传云端，超管支持【测试webdav】；
- ⏱️ **接龙游戏死锁彻底解脱**：支持【重置接龙】/【结束接龙】随时释放，30秒无互动或离线自动瞬间重开；

- 📊 **群生态与宏观经济大屏**：实时可视化全群资金流动性、贫富金字塔阶层与 24 小时群活跃波峰走势；
- 🖼️ **原生图文混排与抽卡体验**：抽卡与图鉴支持 OneBot / Lagrange 原生图像组件分发，告别 CQ 乱码；
- ⚡ **毫秒级极速响应**：全 SQLite WAL 模式、内存 LRU 热缓存、防抖落盘与原子级防刷事务保障。

### 📦 安装与使用：
1. **AstrBot 插件管理器**：在 AstrBot 插件市场或「安装插件」处填入仓库地址 `https://github.com/emmfax/xb` 即可一键安装；
2. **Web 管理后台**：在 AstrBot 后台进入「小白」页面，即可使用全功能管理大屏与玩法配置。
